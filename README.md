## The line

> Describe your app idea in plain words and let an AI agent build it for you today, no coding and no lessons, just your idea turned into a real app you can see and use.

One sentence, 166 characters. A pitch to a friend who has never
coded, answering the only question that matters to them: what do I
have to do, and what do I get?

## Why this line works

- **Persuasion** — it removes all three objections in one breath:
  no coding, no lessons, and the result arrives today.
- **Clarity** — the friend only has to describe the idea the way
  they would tell it to a person; the agent does the building.
- **Truth** — it claims nothing about price or features, only what
  the platform actually does: plain words in, a real app out.
- **Payoff** — the sentence ends on something the friend can see
  and use, which is what turns "maybe" into "yes".

## How to run

Requires Python 3.13 (standard library only, no dependencies).

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` — UTF-8, one sentence,
166 characters, no trailing newline.
